# Знатоки Олимпизма — тренажёр

Подготовка к конкурсу «Знатоки Олимпизма» (Олимпийская научная сессия, Поволжский ГУФКСиТ, 14.11.2026).

- `index.html` — тренажёр: карточки, талисманы, викторина, шпаргалка. Работает офлайн, прогресс — в localStorage.
- `data.js` — база: 51 талисман, 54 карточки, 72 вопроса (составлено по материалам русской Википедии).

## Источники фактов
Русская Википедия: «Античные Олимпийские игры», «Соревнования античных Олимпийских игр», «Олимпийские игры»,
«Летние Олимпийские игры», «Зимние Олимпийские игры», «Летние Олимпийские игры 1896», «Олимпийская символика»,
«Олимпийский огонь», «Олимпийские талисманы», «Международный олимпийский комитет», «Олимпийские виды спорта».

`шпаргалка.docx` — версия для печати/чтения с телефона, те же факты в виде таблиц.

## Открыть
Просто открыть `index.html` в браузере или зайти на GitHub Pages (Settings → Pages → Deploy from branch → main / root).

## Добавить вопросы
Открой `data.js` и допиши в массив `questions`: `{q, options:[4 варианта], answer: номер правильного (с 0), topic, explain}`.
